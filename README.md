Detective GUI

A small detective game with a graphical interface, made with Python and Tkinter.
I wanted to make something more fun and a little bigger than my earlier projects, so I tried combining a simple story with game logic, different choices, and a GUI.

What it does

 • Shows a simple detective story

 • Lets the player make choices

 • Keeps track of the game state

 • Uses an inventory system

 • Has different buttons and screens

 • Uses Tkinter for the interface


How to run

[python detective_gui.py](./08_detective_gui.py)
